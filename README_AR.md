# UPVC Factory Pro — Android Starter

هذه نسخة أولية من واجهة تطبيق أندرويد باللغة العربية (RTL)، مبنية باستخدام Flutter.

## ما الموجود حالياً؟
- لوحة رئيسية عربية.
- بطاقات للوصول إلى العملاء والطلبات والمقاسات والإنتاج وقوائم القص والمزامنة.
- نموذج أولي لإدخال طلب وبيانات العميل ونوع المنتج واتجاه الفتح والعرض والارتفاع.
- شاشات تمهيدية لبقية الوحدات.

## ما الذي لم يُنفذ بعد؟
هذه ليست نسخة إنتاج جاهزة ولا ملف APK. لا توجد حالياً قاعدة بيانات دائمة أو مزامنة أو محرك حسابات وقص. يجب بناء هذه الأجزاء واختبارها على بيانات المصنع الفعلية قبل استخدامها في التصنيع.

## تشغيل المشروع
1. ثبّت Flutter SDK وAndroid Studio على الكمبيوتر.
2. فك ضغط المشروع.
3. افتح مجلد `UPVC_Factory_Pro_Android` في Android Studio أو VS Code.
4. نفّذ:
   - `flutter pub get`
   - `flutter run`
5. لبناء ملف APK تجريبي لاحقاً:
   - `flutter build apk --debug`

## الخطوات التالية المقترحة
1. اعتماد حقول الطلب وأنواع المنتجات.
2. بناء قاعدة بيانات محلية (SQLite) مع ترقيم الطلبات.
3. بناء واجهة الرسم الهندسي والتقسيمات.
4. تصميم واجهة API آمنة للمزامنة مع نسخة Windows.
5. نقل قواعد الحساب والقص المعتمدة إلى محرك مشترك واختبارها قبل الإنتاج.

## ملاحظة مهمة
لا تعتمد أي مقاسات أو خصومات أو قوائم قص ناتجة عن هذه الواجهة الأولية في التصنيع؛ الحسابات الهندسية غير مفعّلة بعد.
